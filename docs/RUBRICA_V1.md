\# Rubrica de Avaliação v1



Esta rubrica será utilizada para avaliar as saídas geradas pelo modelo a partir dos test\_cases.



Escala de avaliação: \*\*1 a 5\*\*



\## 1. Clareza

Avalia se o texto é compreensível e bem estruturado.



1 - Texto confuso ou difícil de entender  

3 - Texto compreensível com pequenas falhas  

5 - Texto claro, objetivo e bem organizado  



\## 2. Completude

Avalia se todas as informações esperadas estão presentes.



1 - Muitas informações faltando  

3 - Informações parcialmente completas  

5 - Informações completas  



\## 3. Aderência ao input

Avalia se a resposta corresponde corretamente ao produto ou serviço solicitado.



1 - Não corresponde ao input  

3 - Parcialmente aderente  

5 - Totalmente aderente  



\## 4. Padronização

Avalia se a resposta segue o formato definido no projeto.



1 - Estrutura inconsistente  

3 - Estrutura parcialmente padronizada  

5 - Estrutura totalmente padronizada
